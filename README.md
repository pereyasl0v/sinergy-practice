# Калькулятор стоимости обучения

React + FastAPI приложение для просмотра **конкретных** тарифов Университета «Синергия» для набора 2026/2027. Данные перенесены из трёх предоставленных приказов — по бакалавриату, специалитету и программам с дистанционными образовательными технологиями (включая СПО и магистратуру).

**Основной принцип:** годовая цена и **полная стоимость за весь период** — два независимых значения, перенесённые из строки приказа. Полная цена **не** вычисляется как «год × четыре». Выбор зависит от уровня образования, формы, варианта подготовки, направления/специальности, профиля, срока и (если прямо предусмотрено) тарифа с гарантированным трудоустройством.

|---|---|---|
| `prikaz_vo_bak_1kurs.pdf` | № 173/3000255 от 04.09.2026 | 3–5 |
| `prikaz_vo_spc_1kurs.pdf` | № 173/3000224 от 30.07.2026 | 3 |

Содержимое структурировано в `backend/app/catalog.json`. Страница источника и реквизиты приказа привязаны к каждой тарифной позиции. Табличный перечень для перепроверки есть в `docs/source_price_audit.csv`.

### Важные ограничения источников

- **Для очных программ** длительность в таблицах в основном отдельно не прописана. В интерфейсе показывается длительность, **рассчитанная по отношению опубликованной полной и годовой сумм**, с предупреждением, что юридически значимый срок нужно подтвердить в договоре.
- **Для дистанционных тарифов** в заголовках таблиц указаны явные альтернативы: СПО — 4/5 лет, бакалавриат — 3,5/4,5 года, магистратура — 2,5 года. Эти варианты существуют **отдельно**, с отдельными полными суммами.
- Дистанционный приказ в нескольких строках даёт **общий тариф без перечня специальностей**. Нельзя считать его подтверждённой стоимостью любой выбранной специальности — приложение это подчёркивает.
- В специалитете две программы опубликованы в **USD**. Приложение показывает оригинальную валюту, **не смешивает** долларовые суммы с введёнными рублёвыми расходами и не придумывает курс.
- «Скидка» и расходы на жизнь являются *сценарием пользователя*, **не частью приказа**. Официальная полная цена постоянно показана отдельно; распределение личного бюджета по годам условное, не график платежей.
- Указаны 176 тарифных строк из **этих трёх документов**, не весь каталог направлений университета.

## Разработка

Зависимости: Node.js 20+, Python 3.11+ и Poetry.

Терминал 1:

```bash
cd backend
poetry install
poetry run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Терминал 2:

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173` — Vite проксирует `/api` на FastAPI. Отдельная сборка в dev-режиме не нужна.

## Production-сборка

```bash
cd frontend
npm ci   # если есть package-lock.json; иначе npm install
npm run build
cd ../backend
poetry install --only main
poetry run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

FastAPI отдаёт React-сборку из `frontend/dist` (файлы `dist` не хранятся в Git). Для публичного развёртывания необходимы HTTPS, прокси и соответствующее ограничение доступа к сервису.

API: `GET /api/catalog`, `GET /api/calculate?program=<id>&months=48&employment=false` и OpenAPI `/docs`.

## Проверки

```bash
cd backend && poetry run python -m pytest -q
```

### Повторный импорт из тех же PDF

Поместите три PDF с указанными именами в отдельную папку и выполните `python tools/rebuild_catalog.py /путь/к/папке` (требуется библиотека `pdfplumber`). Скрипт проверяет, что суммы за курс и первый год дают согласованный срок, и не назначает общие дистанционные цены неупомянутым специальностям. Исходные PDF включены в загружаемый ZIP проекта; в Git-репозитории сохранены данные каталога и CSV для аудита, а не бинарные PDF.
