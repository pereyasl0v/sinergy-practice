# Калькулятор стоимости обучения

Веб-приложение для оценки расходов на учёбу и личного бюджета абитуриента. Содержит выбор программ Университета «Синергия», форму обучения, прогноз на весь срок, моделирование скидки и дополнительные расходы. Внизу страницы приведены ссылки на открытые источники.

## Стек

- **Frontend:** React 19, Vite, JavaScript, CSS.
- **Backend:** FastAPI, Uvicorn, Python; зависимости через Poetry.
- **Данные:** `backend/app/catalog.json`; база данных не требуется.
- **Production:** FastAPI раздаёт файлы после сборки `frontend/dist`; исходники React остаются редактируемыми в `frontend/src`.

## Разработка

Нужны Python 3.11+, Poetry и Node.js 20+.

**Терминал 1 — API** (из `backend/`):

```bash
poetry install
poetry run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

**Терминал 2 — React** (из `frontend/`):

```bash
npm install
npm run dev
```

Откройте адрес, напечатанный Vite (по умолчанию `http://127.0.0.1:5173`). Все запросы `/api` проксируются на FastAPI. При изменении React-интерфейса страница обновляется в режиме разработки.

## Сборка и запуск одним сервером

В папке `frontend/`:

```bash
npm install
npm run build
```

В папке `backend/`:

```bash
poetry install --only main
poetry run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Затем откройте `http://127.0.0.1:8000` — FastAPI отдаст React-приложение из `frontend/dist` и обслужит API на том же порту. `dist/` создаётся при сборке, **не коммитится** и не является исходным кодом. Для обновления фронтенда отредактируйте `frontend/src` и повторите сборку.

На публичном сервере следует настроить HTTPS (например, через обратный прокси) и не запускать Uvicorn с `--reload`.

## API

- `GET /api/catalog` — список тарифов и ссылки на источники.
- `GET /api/calculate?program=b-dev&discount=10&housing=15000` — расчёт стоимости и детализация по годам.
- `GET /docs` — Swagger UI.

## Проверки

Из `backend/`: `poetry run python -m pytest -q`.
Из `frontend/`: `npm run build`.

## Примечания о ценах

В каталоге приложения представлена выборка тарифов из документов на 2026/2027 год. Не все программы университета имеют подтверждённую цену в приложении; где используется общий тариф, это указано возле выбора программы. Скидка и дополнительные расходы задаются пользователем и не являются условиями университета. Итоговый расчёт — ориентир, а не договорная цена.
